# План доработки проекта ROS_test_project

## Обзор
Текущий проект частично реализован. Требуется довести его до соответствия всем пунктам тестового задания: исправить карту стресса, реализовать блокировки узлов/ребер, систему уступок, детектирование застрявших роботов, "Тёмный цех", устойчивость к потере связи и улучшить обработку ошибок.

## Критические несоответствия
1. **Карта stress.yaml** - не соответствует ASCII диаграмме из задания. Текущая карта имеет неправильную структуру, использует несуществующие узлы C1/C5 для старта роботов.
2. **Блокировки/резервирование** - отсутствуют. Роботы могут сталкиваться, не уступают в узких коридорах.
3. **"Тёмный цех"** - не реализован (только упомянут в README как планируемый).
4. **Детектирование застрянных роботов** - оркестратор не блокирует граф при застрявшем роботе, которого ждать бесполезно.
5. **Потеря связи/таймауты** - нет обработки потери соединения с роботом.
6. **Ошибки робота** - нужно лучше реализовать репортинг ошибок (застрял в препятствии, не найдена точка, робот слишком далеко от ближайшей точки/ребра).

## План реализации

### 1. Исправить конфигурацию карты stress.yaml
Согласно ASCII диаграмме:
```
_____________________________
|                            |
|                     O - P  |
|                     |      |
| O - O - O - O - O   O - P  |
| |       |       |   |      |
| O - O - O - O - O - O - P  |
|                     |      |
|                     O - P  |
|                     |      |
|                     O - P  |
|_____________________________
```
Нужно построить правильную графовую структуру узлов/ребер и парковок P1-P5.

Текущая структура не соответствует. Нужно полностью переписать `config_nodes_edges/stress.yaml`, обновить старты роботов на существующие узлы.

### 2. Улучшить симулятор робота (robot_driver.py)
**Требования:**
- Передавать информацию о позиции, скорости, текущем приказе
- Получать и обрабатывать приказы (перемещение, остановка, ручное управление)
- Репортить об ошибках (застрял в препятствии, не найдена точка, робот слишком далеко от ближайшей точки/ребра)
- Двигаться взад и вперёд, поворачиваться

**Доработки:**
- Добавить детектирование застревания: если робот пытается двигаться, но позиция не меняется > N секунд - считается застрявшим
- Проверка удаленности от графа: если робот далеко от всех узлов/ребер (> порог) - ошибка
- Улучшить обработку неизвестных узлов
- Добавить публикацию скорости (linear/angular) в состоянии
- Добавить heartbeat/таймаут для оркестратора
- Обработка команды остановки

### 3. Реализовать продвинутый оркестратор (orchestrator/main.py)
Ключевые требования:
- Учитывать занятость узлов и путей, чтобы роботы друг друга не сбили
- В узких коридорах уступать друг другу  
- Блокировать графы где стоит застрявший робот, которого ждать бесполезно
- Стабилен при плохой связи (троттлинг, потеря связи)
- Реализовать сценарий "Тёмный цех"

**Доработки:**
- **Система резервирований**: таблица занятых узлов и ребер с владельцем и временем истечения
- **Планирование маршрутов с учетом блокировок**: при поиске пути избегать занятых ресурсов
- **Уступки**: если робот не может проехать из-за другого - ждать или перестраивать маршрут
- **Heartbeat/таймауты**: отслеживать последнее обновление состояния от робота. Если > T секунд - считать потерянным соединением
- **Детектирование застрявших**: по состоянию робота и его поведению
- **Блокировка графа**: при застрявшем роботе блокировать проходящие через него узлы/ребра для других, помечая как заблокированные навсегда до ручного вмешательства
- **"Тёмный цех" (Dark Shop)**: фоновый цикл, выбирающий случайные дальние цели для idle-роботов
- **VDA5050-подобный формат**: можно добавить поддержку минимального VDA5050 для orders/states (опционально, но полезно)
- **Улучшенная обработка /order** с учетом резервирований

### 4. Обновить веб-интерфейс (web/)
- Отображение заблокированных узлов/ребер
- Индикатор "Тёмный цех" включен/выключен
- Отображение ошибок роботов более явно
- Кнопка включения/выключения "Темного цеха"
- Статистика потери связи

### 5. Обновить генератор мира (scripts/gen_world.py)
Может потребоваться доработка при изменении структуры карт.

### 6. Документация и тесты
- Обновить README с описанием новых функций
- Добавить инструкции по "Тёмному цеху", блокировкам
- По желанию - базовые тесты

## Приоритет выполнения
1. Исправить stress.yaml (критично для тестирования)
2. Реализовать систему блокировок в оркестраторе  
3. Улучшить детектирование ошибок в роботе
4. Добавить "Тёмный цех"
5. Обработка потери связи и троттлинга
6. Обновить UI
7. Тестирование

## Файлы для изменения
- `config_nodes_edges/stress.yaml` - переделать карту
- `orchestrator/main.py` - крупная доработка (блокировки, dark shop, таймауты)
- `ros_ws/src/robot_sim/robot_sim/robot_driver.py` - улучшения детектирования ошибок
- `web/index.html`, `web/script.js` - UI для новых функций
- `README.md` - обновить документацию

## Особенности реализации
- Блокировки должны учитывать как узлы, так и ребра (по требованию "занятость узлов и путей")
- В узких коридорах роботы должны уступать - можно реализовать через приоритеты или через ожидание
- "Застрявший робот, которого ждать бесполезно" - нужно определить критерий: долго не двигается при движении, заблокировал критический путь
- "Тёмный цех" - когда включен, постоянно выдавать приказы на перемещение по рандомным дальним точкам
- Троттлинг и потеря связи - таймаут на состояние робота, переподключение/обработка
